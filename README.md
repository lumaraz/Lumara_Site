# Lumara Silva: site e sistema

Site público (portfólio, orçamento, página de links) e área da equipe (pedidos, propostas, contratos, projetos, calendário, caixa).

Este primeiro envio é a versão aprovada do protótipo. Os próximos envios ligam o banco de dados (Supabase), os e-mails (Google Workspace) e os pagamentos (InfinitePay), e o site sai pelo Netlify.
